hear_learn
Empowering Visually Impaired Students Through Accessible Education Technology

hear_learn is a comprehensive Flutter-based mobile application designed to bridge the educational gap for blind and partially sighted students. The app creates a seamless connection between visually impaired learners and their teachers, transforming traditional learning materials into accessible, voice-driven experiences.

🎯 Key Features
1. 📚 Shared Learning Space
A collaborative platform where teachers can upload course materials. The system automatically converts PDF documents into speech using integrated Text-to-Speech (TTS) technology, making educational content instantly accessible to visually impaired students.

2. ✅ Voice-Enabled Quiz System
Teachers can create and administer quizzes tailored for blind students. Every question, option, and feedback is fully supported with voice assistance, enabling independent assessment and learning progress tracking.

3. 🎨 Color Recognition
Developed based on direct feedback from interviews with visually impaired users during the development phase. This feature helps users identify colors in real-time, particularly useful when shopping for clothes or selecting items that match their color preferences.

4. 💵 Currency Recognition
Simply take a picture of any banknote, and the app will identify the denomination and currency type via voice output. This feature promotes financial independence and confidence in daily transactions.

5. 🚨 Emergency Button
A one-click emergency feature that instantly notifies designated caregivers with the user's location and situation, providing peace of mind and enhanced safety.

🛠️ Technology Stack
Framework: Flutter

Platform: Cross-platform mobile (iOS & Android)

Key Integrations: Text-to-Speech (TTS), Camera API, PDF Parser, Image Recognition

🎓 Impact
hear_learn was created to solve real accessibility challenges identified through direct interviews with visually impaired students. By combining voice-first design with practical daily-life tools, the app aims to create a more inclusive educational environment where visual ability is not a barrier to learning.
